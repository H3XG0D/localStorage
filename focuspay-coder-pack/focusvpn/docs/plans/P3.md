# Phase 3 — Client AppCore + platforms

> **M1–M5 + M3b/M3c/M4b/M4c/M5b + M6 native libs pipeline done.** Build `.so` / WireGuardKitGo on NDK/Mac hosts.

## Goal

Product clients on top of Phase 2 CP. Thin branded UIs; shared contracts; permissive engines (ADR-003). FocusVPN = FocusPay add-on (Mini App palette).

## P3-M6 DoD

1. Pin **amneziawg-android `v2.0.2`** / **amneziawg-apple `v2.0.3`** (both amneziawg-go **v0.2.19**) ✅
2. `make android-native` builds/copies only `libwg-go.so` (refuses GPL `libwg*`) ✅
3. `scripts/wizard-apple-native.sh` walks WireGuardKitGo + `FOCUSVPN_AWG_GO` ✅
4. `make native-libs-check` without NDK/Xcode ✅
5. NOTICE / READMEs / `.gitignore` for `*.so` ✅

## Follow-ups

- Run `make android-native` on a machine with NDK **or** restore CI ABI artifact (`make android-native-restore`)
- Run `./scripts/wizard-apple-native.sh` on a Mac with entitlements
- App Store / Play signing + production entitlements

## Non-negotiables

- Private keys stay on device
- No GPL/AGPL in product binaries; wintun.dll side-by-side only
- Pin amneziawg-go `v0.2.19` (never tip `…/amneziawg-go/v3` without ADR)
