# ADR-011: Российские сайты и приложения — мимо туннеля

- **Статус:** Принято
- **Дата:** 07.10.2026
- **Основа:** запрос CEO; клиент — [[009-android-vless-only]]

## Контекст

На Android туннель забирал `0.0.0.0/0`. Российский сайт или приложение (MAX, Яндекс Доставка, банки, доставка) видело адрес ноды. ТСПУ и сами сервисы помечают такой адрес и банят его для всех. Пользователь выключал VPN, чтобы домашние приложения снова открывались.

Зарубежный трафик по-прежнему должен идти через VLESS.

## Решение

На Android Xray делит трафик после TUN:

1. Имена `.ru`, `.su`, `.рф`, `.moscow`, `.tatar` и известные чужие зоны российских сервисов (`yandex.net`, `vk.com`, `userapi.com`, …) — outbound `freedom`.
2. Адреса из снимка RIPE NCC `delegated-ripencc` с кодом страны RU, плюс частные сети — тоже `direct`. Снимок: `clients/android/app/src/main/assets/ru-prefixes.txt`, обновление `python3 scripts/refresh-ru-prefixes.py`. Это не база MaxMind.
3. Остальное, включая пробу туннеля на `gstatic`, — outbound `proxy` (он первый, значит маршрут по умолчанию).
4. Имена из пункта 1 резолвятся через `77.88.8.8` с защищённого сокета (реальный IP телефона). Прочие — DoH `1.1.1.1`, как раньше. `domainStrategy: IPIfNonMatch`: если имя не попало в список, адрес всё равно сверяется с префиксами RU. Наружу уходит исходное имя, не подменённый IP.

Сокет `freedom` защищается тем же `VpnService.protect`, что и сокет VLESS, и в TUN не возвращается.

## Последствия

**Плюсы:** адрес ноды не светится российским сайтам с телефона; MAX, Яндекс и остальные `.ru` не требуют выключать VPN.

**Минусы:** российский сервис видит домашний IP — это и есть цель. Снимок RIPE не равен «всем IP, которые кто-то считает российскими»: сервис на чужом префиксе и чужом имени всё ещё выйдет через ноду. GUI Linux и Windows используют тот же список. ## Альтернативы

- Выкидывать приложения по package name. Список пакетов гниёт, и «русские сайты» так не покрыть.
- Вшить `geoip.dat` / `geosite.dat`. У MaxMind CC-BY-SA, файл толстый, а снимок RIPE читается в ревью.
- Узкий список только MAX и Яндекса. Любой другой российский сайт снова палит адрес ноды.
