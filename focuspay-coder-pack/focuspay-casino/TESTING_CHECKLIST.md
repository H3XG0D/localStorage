- [ ] Webhook настроен (если нужен для пополнения)
- [ ] nginx конфигурация активна
- [ ] Оба сервиса запущены и active

- [ ] Hold корректно блокирует баланс

- [ ] Payout корректно зачисляет выигрыш
- [ ] Комиссия 15% рассчитывается правильно
- [ ] Creator получает 5%

- [ ] Referral L2 получает 2% (если есть)
- [ ] Owner получает остаток (6-10%)
