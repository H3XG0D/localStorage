# Focus Pay — партнёрский бот + Mini App

## Что умеет
- Анимированные баннеры: маленький сверху на весь ролик + карточка 25% экрана со звуком в середине. У каждого автора свои, с промокодом (animate.py).
- Админ-панель (/admin): статистика за период, очередь роликов и выводов кнопками, авторы, бонусы/штрафы, идеи, рассылка, ставки, выгрузки в Excel, сводка каждый день.
- Приложение в Telegram: баланс, заявки со статусами, уровни, серии, рефералка, топ (по просмотрам и по клиентам).
- Персональный промокод и ссылки под каждую площадку у каждого автора; персональные баннеры с промокодом генерируются сами.
- Учёт клиентов в обменнике по промокодам и ссылкам (нужна связка, см. INTEGRATION.md). Бонус автору за клиента выключен (CLIENT_REWARD=0).
- Бонусы: за первый ролик и за каждые 100 принятых роликов; статистика автора в профиле.
- Идеи для бота: авторы предлагают и голосуют, ты меняешь статус командой /idea.
- ИИ-поддержка: бот отвечает авторам сам, видит их заявки и выплаты; сложное — кнопкой «Позвать человека» тебе.
- Автопроверка YouTube Shorts через официальный API: реальные просмотры, лайки, флаги накрутки, автоприём чистых заявок.
- Промокоды: после первого принятого ролика код становится скидкой 200 ₽ на обмен от 3 000 ₽ (100 активаций) в FocusPay. Статистика приходов и активаций — в профиле автора и в админке → Промокоды. Проверка для операторов обменника — /operator.
- Админы и операторы добавляются в админке → Ещё → «Админы и операторы».
- Команды админа: /stats, /pending, /traffic, /reply ID текст, /broadcast текст, /ideas, /idea ID progress|done|reject, /ban ID, /unban ID.


Бот и приложение работают в одной программе `bot.py`. Для теста сервер не нужен: всё крутится на твоём компе, а Telegram получает доступ через бесплатный туннель Cloudflare.

## 1. Подготовка (один раз)
1. Установи Python 3.11+ с python.org. В установщике отметь **Add Python to PATH**.
2. Создай бота в @BotFather → /newbot → скопируй токен.
3. Узнай свой id у @userinfobot.
4. Распакуй архив, например в `C:\focuspay_partner_bot`.
5. Скопируй `.env.example` → `.env`, открой Блокнотом и заполни BOT_TOKEN, ADMIN_IDS, EXCHANGE_TG, SUPPORT_TG.
6. Положи озвучку (.mp3) и баннеры (.png) в папку `materials`.

## 2. Установка (Windows, командная строка в папке проекта)
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Проверка в браузере (без Telegram)
```
python bot.py
```
Открой http://localhost:8080 — увидишь приложение (работает при DEV_MODE=1, ты заходишь как админ).
Бот в Telegram уже отвечает в чате.

## 4. Mini App внутри Telegram
1. Скачай `cloudflared-windows-amd64.exe` со страницы релизов github.com/cloudflare/cloudflared, переименуй в `cloudflared.exe` и положи в папку проекта.
2. В **отдельном** окне командной строки:
   ```
   cloudflared.exe tunnel --url http://localhost:8080
   ```
   В выводе появится ссылка вида `https://что-то.trycloudflare.com`.
3. Вставь её в `.env` → `WEBAPP_URL=https://что-то.trycloudflare.com`
4. Перезапусти бота (Ctrl+C и снова `python bot.py`).
5. В Telegram напиши боту /start → появятся кнопка «📱 Открыть приложение» и кнопка «Приложение» слева от поля ввода.

Туннель живёт, пока открыто окно. При новом запуске ссылка другая — обнови WEBAPP_URL и перезапусти бота. Это нормально для теста; на VPS будет постоянный домен.

## Как протестировать всё самому
1. Открой приложение → прими правила.
2. «Сдать» → площадка, любая ссылка с этой площадки, 25000 просмотров, любой скрин.
3. Тебе (как админу) в бот придёт заявка → «Принять» → напиши «ок».
4. В приложении баланс вырастет, у заявки статус «Принята». Чтобы проверить вывод, сдай несколько заявок, пока баланс не станет от 2 000 ₽.
5. Рефералка: открой бота со второго аккаунта по ссылке из профиля.

Команды админа в боте: /stats, /pending, /ban ID, /unban ID.

## Перед запуском для реальных авторов
- поставь `DEV_MODE=0`;
- переезжай на VPS с постоянным доменом;
- делай копию `focuspay.db` раз в день — это вся база.
