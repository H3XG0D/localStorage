# Review 2026-08-21

## TL;DR

• **Продуктивность 12.08 выдающаяся** — выкачены память Ops AI, multi-agent, self-check, Telegram-дайджест, критичный инцидент #1 (калькулятор LTC) разгрёбен с регрессионными тестами.

• **OWASP P1 открыты 6+ дней** — guest cookie, finance ACL для операторов, captcha, referral escape не закрыты. **Ready for Production: No**. Нужен fix-спринт за 48 ч с жёстким дедлайном.

• **Финансовый учёт не ведётся** — FocusPay-PnL пуст с момента запуска в прод, капитал/комиссии не зафиксированы, рентабельность неизвестна. Burn ~525 USD/мес по личным расходам.

• **Нулевая видимость операций** — нет метрик по заявкам операторов (количество, SLA, просрочки), ночные смены без контроля загрузки, риск выгорания и ошибок.

• **Интеграция VPN заблокирована** — бот готов, но не задеплоен; FR dedicated под трафик не заказан; пока FocusPay уязвим (P1), тащить в общий ledger опасно.

• **Критичные дыры инфры** — webhook без IP whitelist (фейковые платежи), offsite backup не настроен (потеря при отказе сервера), tg_bot_btc без git (нет версионирования).

• **Приоритет на 2 дня**: День 1 — закрыть OWASP P1 + webhook IP lock + ротация секретов + offsite rsync; День 2 — git init бота + snapshot финансов + метрики операторов в дайджест.

• **Quick wins готовы** — алерт на опасные действия в боте (10 строк, убирает жалобу), P&L-дайджест из SQL, `.env`-validator в CI блокирует деплой без секьюрити-настроек.

## ProductAuditor

### Риски

1. **OWASP P1 открыты** — Ready for Production: No. Guest cookie, finance ACL для admin ops, отсутствие captcha, html.escape в referral — всё это эксплуатируемо. Бот в проде, но уязвим.

2. **Webhook без IP whitelist** — `WEBHOOK_ALLOWED_IPS` не задан, `REQUIRE=1` не включён. Payfast callback может приходить откуда угодно → фейковые уведомления о платежах.

3. **Потенциальная утечка секретов** — если `.env` / root-пароль / Lelouch token / bot token светились, нужна ротация. В TODO висит, но не сделано.

4. **Offsite backup не настроен** — `OFFSITE_RSYNC` в `/etc/focuspay/backup.env` не прописан. Если сервер умрёт, локальные бэкапы пропадут вместе с ним.

5. **Freeze блокирует быстрые фиксы финансов** — если вскроется ошибка в `financial_guards` / `buy_payout_validate`, фикс требует явного approve. Правильно, но может затянуть critical hotfix.

### Долг

1. **tg_bot_btc без git** — нет версионирования, нет истории, нет возможности откатиться или посмотреть diff при инциденте.

2. **Ревизия функций бота не проведена** — что просело, что докрутить — висит в Backlog без оценки.

3. **MYVPN интеграция отложена** — единая БД пользователей + баланс VPN из бота в Future, промо VPN внутри FocusPay тоже. Экосистема не связана, упущенная аудитория.

4. **Security scan в CI** — скрипт есть (`scripts/security_scan.sh`), но непонятно, блокирует ли он deploy при регрессии. Если нет — долг процесса.

5. **Multi-agent Ops AI без метрик** — система выкачена, но нет замеров точности triage, false positive findings, времени на задачу. Работает вслепую.

### Приоритеты на 2 дня

1. **День 1: OWASP P1 + webhook IP lock**  
   Закрыть guest cookie, finance ACL admin ops, captcha, html.escape referral. Задать `WEBHOOK_ALLOWED_IPS` (IP Payfast) + `REQUIRE=1`. Это prod-безопасность.

2. **День 1 вечер: ротация секретов**  
   Сменить root-пароль, проверить логи на утечку Lelouch/bot token → ротировать если светились. Прописать `OFFSITE_RSYNC` в `/etc/focuspay/backup.env` и запустить тест.

3. **День 2: git init + ревизия бота**  
   `git init` для `tg_bot_btc`, добавить приватный remote, первый commit. Пройти по функциям бота (done/useful, exchange flow, templates) — что тормозит, что сломано, что доделать. Зафиксировать список.

- Ручной анализ переписок операторов на предмет проблем клиентов
- Ручной анализ трендов в «Админ отчеты» (упоминается 2026-08-11, 2026-08-12)

**UX-проблемы из чатов:**
- Случайное отключение уведомлений без подтверждения (2026-08-11 06:42, жалоба оператора)
- Нет алерта при критичных действиях в боте

### Идеи автоматизации (effort S/M/L)

**S — Quick scripts (часы):**
1. **Скрипт генерации fix-чеклиста** из OWASP-отчёта → Markdown с чекбоксами + приоритетами (парсит `SECURITY_AUDIT_OWASP_*.md`).
2. **Алерт на случайное action** — Telegram confirmation для «отменить заказ» / «выключить уведомления» (guard в `tg_bot_btc/handlers`).
3. **`.env`-validator** — CI-проверка, что `WEBHOOK_ALLOWED_IPS`, `OFFSITE_RSYNC` заполнены перед деплоем на прод.

**M — Bot features (дни):**
4. **Дайджест P&L в Telegram** — еженедельная сводка: капитал, обороты, комиссии, топ-5 операторов (SQL → `focuspay-ops-ai-digest` расширить).
5. **Ops insight из чатов** — ML-парсинг `operator_chat_messages`: частые жалобы клиентов, длинные треды без резолюции → еженедельный отчёт админу.
6. **Secret rotation playbook** — CLI-тул `scripts/rotate_secrets.sh` с подсказками (генерирует новые токены, обновляет `.env`, перезапускает сервисы, чекает health).

**L — Platform upgrades (недели):**
7. **Auto-remediation OWASP P2/P3** — CI-pipeline с автофиксами: `html.escape` инъекции, `rate_limit` на эндпоинты без защиты, CORS whitelist sync.
8. **Real-time fraud detection** — ML-модель на аномальные заказы (сумма, частота, geo IP) → автостоп + алерт в «Админ отчеты».
9. **Self-healing infrastructure** — Ansible playbook: если `focuspay-selfcheck` видит auth wall down 3 раза подряд → auto-restart uwsgi, логирует в Sentry.

### Quick wins

1. **Алерт на опасные действия** (S) — добавить `inline_keyboard` с «Да, отключить уведомления» в боте; 10 строк кода, убирает жалобу из 2026-08-11.
2. **P&L-дайджест** (M) — SQL-запрос `SUM(profit)`, `SUM(cashback_spent)` за неделю → в существующий `focuspay-ops-ai-digest`; видимость финансов без ручного ввода.
3. **`.env`-validator в CI** (S) — `scripts/validate_env.sh` + GitHub Action; блокирует деплой с пустым `WEBHOOK_ALLOWED_IPS` (TODO-задача исчезает).

4. **Payfast заморожен** — прямая оплата VPN картой/СБП отложена (FROZEN); shortfall-счета через крипту пока тоже не выкачены (slice 2 MVP).

### Следующий маленький шаг

Задеплоить VPN-бот на focuspay biz:
- Прописать токен бота + `X-Internal-Token` обоих сервисов в env.
- Поднять `bots/myvpn-tg` под systemd.
- Smoke-тест: `/start` → ensure FocusPay user → upsert MYVPN user → показать баланс + кнопку «Оплатить неделю».

Это разблокирует ручную проверку федерации (hold→extend→confirm) без ожидания FR dedic.

### Зависимости от команды

- **Фикс FocusPay OWASP P1** — пока открыты, интеграция несёт риск (особенно finance ACL для операторов external, которые теперь будут видеть VPN-транзакции через общий ledger).
- **Prod-токены VPN-бота** — сгенерировать через BotFather, прописать в `.env` обоих проектов (FocusPay Internal API + MYVPN control plane).
