## OpsReviewer

### Слабые места (смены, скорость, эскалации)
- Обнаружение открытых уязвимостей OWASP P1, что указывает на возможные пробелы в проактивной безопасности и эскалации решений.
- Долгое время реагирования на проблемы с курсами и калькуляцией криптовалют, что могло привести к недовольству пользователей.
- потенциальные задержки в сменах операторов, что может вызывать сбои в работе сервиса в часы пик.

### Рекомендации (3 пункта, конкретно)
1. **Ускорить процесс обработки уязвимостей OWASP** путем создания команды быстрого реагирования, которая будет сосредоточена на оперативном устранении открытых проблем.
2. **Оптимизировать процессы и инструменты для расчета курсов криптовалют**, чтобы снизить вероятность ошибок и обеспечить более быструю реакцию на изменения на рынке.
3. **Внедрить регулярные тренинги и оценку операторов** для повышения их квалификации и повышения осведомленности об актуальных угрозах и методах реагирования, что может помочь в снижении эскалаций.

- Разработка и тестирование новой финансовой логики требует значительного времени и ресурсов, особенно с учётом существующих лимитов в FROZEN.

## AutomationScout

### Паттерны ручной работы

1. **Проверка OWASP уязвимостей (P1):** Часто требуются вручную проверять и исправлять уязвимости, такие как guest cookie и finance ACL. Это можно автоматизировать с использованием скриптов для мониторинга и уведомлений о присутствии уязвимостей.

2. **Ротация секретов:** В случае утечки секретов необходимо вручную обновлять и проверять файлы `.env`. Можно создать скрипт, который будет автоматизировать процесс ротации и обновления секретов.

3. **Обратная связь от пользователей:** Сбор отзывов о работе бота и функционале может проходить вручную, через чаты или опросы. Использование бота для автоматизации отзывов и генерации отчетов о пользовательских мнениях можно предложить как автоматизацию.

### Идеи автоматизации (effort M)

1. **Автоматизированный аудит безопасности:** Создание скриптов, которые будут периодически проверять наличие OWASP уязвимостей и генерировать отчеты о состоянии безопасности.

2. **Сбор и обработка отзывов:** Разработка бота, который будет собирать отзывы пользователей о работе системы и автоматически формировать сводки для анализа.

3. **Управление секретами:** Создание системы для автоматической ротации секретов и мониторинга их утечек, вместо ручного обновления.

### Quick wins

1. **Скрипт для автоматизированного аудита OWASP (effort S):** Реализация простого скрипта, который будет проверять наличие базовых уязвимостей и уведомлять команду о новостях.

2. **Бот для сбора отзывов пользователей (effort M):** Быстрая разработка чат-бота для сбора пользовательских мнений и автоматической генерации отчетов.

3. **Скрипт для периодической проверки секретов (effort S):** Реализация простого скрипта, который будет проверять файлы на наличие неподходящих секретов и уведомлять разработчиков.

# Объединение: единая идентичность + общий ₽-баланс + VPN-бот

**Статус:** в реализации (E1). Не одна физическая БД — **федерация** ([[Projects/MYVPN/adr/007-ecosystem-billing-federation|ADR-007]]).

## Решение

1. **FocusPay Postgres** — Telegram `user_id`, рефералы, единый ₽ ledger (cashback/referral/partner).
2. **MYVPN Postgres** — VPN users (`telegram_id`), devices, subscriptions, configs.
3. **Отдельный VPN Telegram bot** (`bots/myvpn-tg`):
   - на `/start` — ensure FocusPay user + upsert MYVPN user;
   - оплата недели с баланса FocusPay (hold→extend→confirm);
   - shortfall — crypto-invoice через FocusPay.
4. Internal API с `X-Internal-Token` в обоих сервисах. Контракты: [[Projects/MYVPN/plans/E1-vpn-bot]].

## Платежи (текущие идеи → MVP)

| Канал | Статус |
|---|---|
| Списание с единого ₽-баланса FocusPay | MVP |
| Крипто-счёт (USDT/BTC) на shortfall | MVP slice 2 |
| Карта/СБП Payfast напрямую за VPN | позже (FROZEN Payfast) |

Пример: кэшбек 300₽ + цена недели 300₽ → полная оплата с баланса без крипты.

- [x] Account-linking model (telegram_id ↔ MYVPN user) — ADR-007
- [x] API пополнения/списания (контракт) — E1 plan
- [x] Общая БД vs федерация — **федерация**
- [ ] Deploy bot + tokens in prod
