# Система управления подписками и ROI-трекинг

## Обзор

Новая система для управления периодическими расходами (подписки, зарплаты, маркетинг) с автоматическим расчётом ROI и рекомендациями по продлению.

## Структура

### Backend

**Таблица:** `recurring_expenses`
- Хранит подписки с циклом оплаты (weekly/biweekly/monthly/quarterly/annual)
- Отслеживает следующую дату платежа (`next_billing_date`)
- Связывается с метриками (партнёры, промо-коды) для расчёта ROI
- Поддерживает мягкое удаление через `is_active`

**Расширение:** `manual_expenses`
- Добавлены поля для связи с recurring_expenses
- ROI-метрики для разовых расходов
- Связь с партнёрами и промо-кодами

**API:** `/api/admin/recurring-expenses`
- `GET /` — список с фильтрами (category, is_active)
- `POST /` — создание подписки
- `PATCH /{id}` — редактирование
- `DELETE /{id}` — архивация (soft delete)
- `POST /{id}/bill` — создать платёж вручную
- `GET /upcoming` — ближайшие платежи (7/14/30 дней)
- `GET /roi-analysis` — ROI-анализ с рекомендациями

**Расчёт ROI:**
- Если привязан партнёр → берём `paid_fiat_sum` за период
- Если привязан промо-код → берём оборот кампании
- ROI % = ((actual_return - amount) / amount) × 100
- Рекомендация "продлевать" если ROI > 20%

### Frontend

**Страница:** `/x8/recurring-expenses` (`AdminRecurringExpenses.tsx`)

**Структура:**
1. **KPI-панель (6 карточек):**
   - Ежемесячно (сумма активных подписок)
   - Ближайшие 7 дней (сумма и количество)
   - ROI средний
   - Прибыльных / Убыточных
   - Всего расходов (lifetime)

2. **Табы:**
   - **Подписки** — recurring_expenses (активные/все/архив)
   - **Разовые** — manual_expenses
   - **ROI-анализ** — сводка с рекомендациями

3. **Таблица подписок:**
   - Название, категория, сумма
   - Цикл оплаты, следующая дата
   - ROI % (badge: зелёный >50%, жёлтый 20-50%, красный <20%)
   - Статус (Прибыльно / Окупается / Проверить / Отслеживается)
   - Действия: редактировать, оплатить сейчас

4. **График расходов:**
   - LineAreaChart по месяцам
   - 4 серии: подписки, зарплаты, маркетинг, прочее
   - Цвета по категориям (blue/purple/orange/yellow)

5. **ROI-анализ:**
   - Карточки с рекомендациями
   - Сравнение расход/возврат/ROI
   - Связь с партнёрами и оборотом
   - Предупреждения для убыточных расходов

**Модальное окно:**
- Форма создания/редактирования подписки
- Поля: название, категория, сумма, цикл, дата
- Опциональная привязка к метрикам (партнёр/промо/custom)
- Ожидаемый возврат для ROI-расчётов

**Интеграция:**
- `FinanceTab` — добавлена строка "Подписки (recurring)" в ExpenseBreakdown
- `AdminRoutes` — новый пункт меню "Подписки и ROI" в секции "Деньги"

## Ребрендинг ChannelsTab

**Обновлённая страница:** `/x8?tab=channels`

**Новая структура:**

1. **KPI-панель (4 карточки):**
   - Всего партнёров
   - Новые партнёры за период
   - Оборот рефералов
   - ROI промо-кампаний (средний %)

2. **Рефералы:**
   - Современная таблица с аватарами
   - Прогресс тиров (progress bar)
   - Тренды по новым клиентам
   - График: динамика топ-5 партнёров

3. **Промо-кампании:**
   - KPI по кампаниям
   - ROI-индикаторы (badge с цветами)
   - Bar chart: ROI % по топ-10 кампаниям
   - Конверсия и оборот

4. **Внештат:**
   - Обновлённые KPI
   - Современный дизайн карточек
   - Метрики за период

## Дизайн-система

**Цвета категорий:**
- Подписки: `var(--blue)`
- Зарплаты: `var(--purple)`
- Маркетинг: `var(--orange)`
- Прочее: `var(--yellow)`

**ROI-индикаторы:**
- \> 50%: зелёный badge "Прибыльно"
- 20-50%: жёлтый badge "Окупается"
- < 20%: красный badge "Проверить"
- null: синий badge "Отслеживается"

**Типографика:**
- Все суммы: `font-mono tabular-nums`
- Проценты, даты: `font-mono`
- Названия: Inter (sans)

## Деплой

### Миграция БД (требует подтверждения)

```bash

python site/exchange-backend/run_migration.py site/exchange-backend/migrations/0034_add_recurring_expenses.sql
```

### Фронтенд

```bash
cd focussite/frontend
npm run build
FOCUSPAY_SSH_PASSWORD=... python scripts/deploy_all.py --dry-run  # проверка
FOCUSPAY_SSH_PASSWORD=... python scripts/deploy_all.py             # деплой
```

### Проверка

1. Открыть `/x8?tab=channels` — проверить обновлённый дизайн
2. Открыть `/x8/recurring-expenses` — проверить новую страницу
3. Создать тестовую подписку
4. Проверить интеграцию в `/x8?tab=finance`

## Безопасность

- Миграции используют `IF NOT EXISTS` для безопасности
- Бэкап БД обязателен перед миграцией
- Откат фронтенда: `.bak-<timestamp>` файлы
- Soft delete: подписки не удаляются физически
