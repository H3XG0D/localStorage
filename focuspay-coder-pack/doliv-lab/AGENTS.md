# AGENTS.md — Doliv Lab (песочница)

Изолированная песочница, форк `~/Desktop/doliv`. Здесь разрабатываются: **рабочие депозиты, work-токены, тимлиды, учёт float**.

Язык общения — русский. Английский только в коде, командах, путях и идентификаторах.

## Границы (важно)

| Каталог | Правило |
|---|---|
| `~/Desktop/doliv` | Baseline — **только чтение**, не править |
| `~/Desktop/tg_bot_btc` | Живой бот — **не трогать** |
| этот каталог | Здесь работаем |

Порты специально сдвинуты, чтобы не конфликтовать с baseline:

| Сервис | Здесь | В baseline |
|---|---|---|
| API | `8002` | 8000 |
| Frontend | `5175` | 5173 |
| Postgres | `5433` | 5432 |

Volumes тоже отдельные: `postgres_lab_data`, `upload_lab_data`.

## Состояние git

git-репозиторий инициализирован (`master`), но **коммитов нет** — всё в untracked. Первый коммит делать только по явной просьбе, предварительно проверив `.gitignore` на попадание `.env`, `.venv`, `node_modules`.

## Стек

Идентичен baseline: FastAPI + SQLAlchemy async + PostgreSQL 16 / React + Vite + TS + Tailwind. Те же запиненные версии в `backend/requirements.txt`.

## Запуск

```bash
docker compose up --build
```

Проверка: API на `:8002`, фронт на `:5175`, Postgres на `:5433`.

Env-файл песочницы — `.env.lab`.

## Правила

- Не коммитить, не пушить, не деплоить без явной просьбы.
- Не печатать значения секретов из `.env.lab`.
- Миграции — новой ревизией Alembic.
- `docker compose down -v` уничтожает данные песочницы — только с подтверждением.
- Проверять, что правки не утекли в baseline `doliv`.
